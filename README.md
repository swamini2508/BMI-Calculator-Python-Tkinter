# BMI Calculator using Python & Tkinter

A simple GUI-based BMI Calculator built using Python and Tkinter.

## Features

- Enter name, height, and weight
- Calculate BMI automatically
- BMI category classification
- Input validation
- Error handling
- Clear button to reset the inputs
- User-friendly GUI

## Technologies Used

- Python
- Tkinter

## BMI Categories

| BMI | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |
